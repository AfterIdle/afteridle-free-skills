# Context Handoff: blank templates

Copy one into a note, the top of your doc, a README, or a ticket.

## Short (when tired)
```
Handoff [date]: [task]. Last: [last done].
Next: [exact next action] (~[X] min)
```

## Standard
```
## Handoff: [task]   ([date], energy at stop: [level])
Goal:
State:
-
Last done:
Next action: ← start here
Open questions:
Files & links:
Gotchas:
Can wait:
Pick up next time:
```

## For another AI chat or agent
```
Context for a fresh assistant: [background, constraints, what done means]
## Handoff: [task]   ([date])
Goal:
State:
Last done:
Next action: ← start here
Files & links:
Don't:
Pick up next time:
```

## Resume
```
## Resume: [task]   (handoff from [date])
Goal:
You were:
Check first (~2 min):   (only if older than stale_after)
First action: ← start here
Then:
```

## Next-action checklist
- Starts with a verb (open, write, send, run, decide, reread).
- Names the exact thing and place (file and line, doc and heading, page, email thread).
- Fits in one block, ideally under 15 minutes.
- No secrets: point to where they live instead.
